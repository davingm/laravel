# Bundle Directory

Distributable zip archives of the framework, for manual distribution without waiting for a Packagist/npm release.

## Generate a bundle

From the monorepo root:

```bash
php scripts/bundle.php --version=X.Y.Z
```

Output: `laravel-betavX.Y.Z.zip`

## Naming convention

| Format | Example | Meaning |
|---|---|---|
| `laravel-betavX.Y.Z.zip` | `laravel-betav0.1.0.zip` | Pre-release / dev bundle |

## Using a bundle

1. Extract the zip to a new folder
2. `cd <folder>`
3. `composer run setup`

## What is included

- Full playground source (`src/`, `app/`, `config/`, etc.)
- Clean `composer.json` pointing to Packagist (no monorepo path repos)
- `.env.example`, `package.json`, `vite.config.js`
- Empty storage directories with `.gitkeep`

## What is NOT included

- `vendor/` — installed by `composer run setup`
- `node_modules/` — installed by `npm ci`
- `.laravel/` — generated by Composer plugin
- `public/build/` — generated by `npm run build`
- `.env` — copied from `.env.example` by setup

## Notes

- This folder is git-ignored. Zip files are never committed.
- The `.gitkeep` file keeps this folder tracked in git.
- Multiple versions can coexist: `laravel-betav0.1.0.zip`, `laravel-betav0.2.0.zip`, etc.
