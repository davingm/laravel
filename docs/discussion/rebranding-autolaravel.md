# Arsip: proposal rebranding AutoLaravel

> **Status: arsip historis.** Proposal di bawah tidak menggambarkan metadata package atau panduan aktif. Nama Composer project saat ini adalah `davingm/laravel`; namespace, nama package, command, dan fitur harus diverifikasi dari manifest serta source yang aktif.

Dokumen lama ini mencatat gagasan rebranding menuju nama `AutoLaravel` dan namespace/package dengan prefix `auto`. Proposal tersebut tidak pernah menjadi sumber kebenaran implementasi. Jangan gunakan contoh command, namespace, konfigurasi, atau nama package dari catatan historis ini untuk aplikasi baru.

Gunakan [panduan instalasi](../guidness/02-instalasi.md), [indeks dokumentasi](../README.md), dan file `composer.json` terkait untuk instruksi yang sesuai dengan repository saat ini.
