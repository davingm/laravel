# Tutorial cara menjalankan proyek laravel + nextjs (dosen)

## Steps 1.

Masuk ke folder backend di terminal. buka termianl ketik 

```bash
cd backend
```

lalu jalankan proyek laravel

```bash
php artisan serve
```

> serve bukan server

## Steps 2

buka terminal baru lalu masuk ke folder frontend di sana ketik

```bash
cd frontend
```

lalu jalankan frontend, ketik

```bash
pnpm dev
```

## Finnaly

setelah selesai buka link ini di browser [http://localhost:3000/](http://localhost:3000/)
