# davingm/argon

Laravel 12 starter for PHP 8.2+, with the Argon Dashboard source template and a borrowing-system backend based on `packages/devtools/src/stubs/presets/peminjaman`.

## Installation

```sh
composer create-project davingm/argon my-app
```
